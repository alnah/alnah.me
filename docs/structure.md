# Structure

- `src/content/`
  Markdown posts and pages
- `src/pages/`
  routes such as home, articles, categories, tags, about, privacy, RSS,
  `robots.txt`, and `index.json`
- `src/components/`
  UI components
- `src/layouts/`
  page and post layouts
- `src/lib/`
  content, SEO, search, and build-shared helpers
- `src/config/`
  site metadata and contact links
- `src/styles/`
  cascade layers and design tokens
- `src/assets/`
  local assets
- `public/`
  static files and generated publish artifacts
- `scripts/`
  build and verification scripts
